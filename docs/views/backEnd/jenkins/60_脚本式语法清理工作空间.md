## 语法示例

```shell
node {
  stage('Init') {
     // 使用内置命令强制删除当前工作目录
     deleteDir();
  }
  
  stage('git clone') {
    git branch: 'dev', credentialsId: '713e4f58-0988-4af8-b70a-a8857xxx', url: 'https://gitee.com/wyw-s/xxx.git';
    sh 'pwd';
  }
}

```
